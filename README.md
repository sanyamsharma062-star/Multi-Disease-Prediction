# 🧠 Project Overview

The Multi-Disease Prediction System is a full-stack machine learning application designed to demonstrate how trained machine learning models can be integrated into a real-world web application.

The system allows users to select a disease, enter the required medical parameters, and receive a prediction generated by the corresponding machine learning model.

The current version supports:

- 🩸 Diabetes Prediction
- ❤️ Heart Disease Prediction
- 🧠 Parkinson's Disease Prediction

The application is designed using a modular architecture so that additional disease prediction models can be integrated in the future.

The project combines concepts from:

- Machine Learning
- Data Science
- Python
- REST API Development
- FastAPI
- React
- Frontend Development
- Software Engineering
- Git and GitHub

---

# ❓ Problem Statement

Machine learning models are frequently developed in Jupyter notebooks or Python scripts. While these environments are useful for experimentation and research, they do not provide a convenient interface for normal users.

The problem addressed by this project is:

> How can multiple machine learning disease-prediction models be integrated into a single web application that provides a simple, validated, and scalable interface for prediction?

The project solves this problem by separating the system into different layers:

Frontend → Backend API → Machine Learning Models

This architecture makes the application easier to develop, test, maintain, and extend.

---

# 💡 Motivation

The primary motivation behind this project is to understand the complete lifecycle of a machine learning application.

Instead of stopping after training a model, this project demonstrates how a trained model can be integrated into a complete software system.

The complete lifecycle is:

Dataset → Data Preprocessing → Model Training → Model Evaluation → Model Serialization → Backend Integration → REST API → Frontend Integration → User Prediction

This provides practical experience in both Machine Learning and Full-Stack Development.

# ⚙️ How the System Works

The system follows the following process.

### Step 1 — Select a Disease

The user selects one of the available disease prediction modules.

Currently available:

- Diabetes
- Heart Disease
- Parkinson's Disease

### Step 2 — Enter Required Parameters

The frontend displays the input fields required by the selected disease model.

### Step 3 — Submit Prediction

The user submits the form.

The React frontend prepares the input data and sends it to the appropriate backend API.

### Step 4 — API Request

The frontend sends an HTTP POST request.

For example:

POST /prediction/diabetes

### Step 5 — Input Validation

FastAPI and Pydantic validate the incoming request.

The backend checks that the correct number of features has been provided.

### Step 6 — Data Conversion

The validated input is converted into a NumPy array.

### Step 7 — Machine Learning Prediction

The corresponding trained model receives the input and generates a prediction.

### Step 8 — API Response

The backend returns a JSON response containing the prediction.

Example:

{
  "prediction": 1,
  "result": "Diabetic"
}

### Step 9 — Display Result

The React frontend receives the response and displays the prediction to the user.

# 🔐 Input Validation

The backend uses Pydantic RootModel validation.

Each disease has its own validation class.

The validation process is:

User Input
↓
Pydantic Validation
↓
Check Feature Count
↓
Valid Input
↓
NumPy Array
↓
Machine Learning Model
↓
Prediction

If the wrong number of features is provided, FastAPI rejects the request.

For example, if the diabetes model expects 8 features but receives 7, the request will not be passed to the model.

This helps prevent invalid API requests.

# 🔄 Complete Prediction Flow

The complete prediction process is:

1. User opens the web application.
2. User selects a disease.
3. Frontend displays the required input fields.
4. User enters the required parameters.
5. React collects the values.
6. React sends an HTTP POST request.
7. FastAPI receives the request.
8. Pydantic validates the input.
9. Input is converted into a NumPy array.
10. Appropriate machine learning model is selected.
11. Model performs prediction.
12. Backend converts the result into JSON.
13. JSON response is returned to React.
14. React displays the prediction result.

The backend uses exception handling around the prediction process.

Example:

{
  "detail": "Diabetes prediction failed. Please try again."
}

Similar error handling is implemented for:

- Heart disease prediction
- Parkinson's prediction

Input validation errors are handled automatically by FastAPI and Pydantic.
